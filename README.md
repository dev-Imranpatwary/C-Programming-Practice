# UIU-ICS(Introduction to Computer System)

📘 **About the Course**  
**Course Code:** CSE 1110

The Introduction to Computer Systems course introduces key concepts of computer hardware, software, and basic programming concepts in C. It covers how a computer operates—taking input, processing data, storing information, and producing output. Students also learn logic building and problem-solving using pseudocode and flowcharts.
